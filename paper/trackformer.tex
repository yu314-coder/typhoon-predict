{\sffamily\bfseries\color{ink}Abstract\par}
Trackformer 1.2 forecasts tropical-cyclone motion and central pressure by
jointly advancing a basin-scale atmospheric state and a translating pressure
core. Recurrent convolutional networks evolve the fields, while multiscale
attention supplies environmental context. A pressure-associated centre and
central-pressure sample are read from the evolving core at each six-hour
step. Twenty autoregressive transitions produce a five-day forecast.
This report specifies the released architecture, state updates, learning
objectives and 50-member input-perturbation policy. Across 1,473 daily forecasts
from 270 storms, equal-storm mean track error is 471.2 km for the 1.2 ensemble
and 798.4 km for the causal 1.1 route pipeline.
The pipelines differ; this is not an architecture ablation or an untouched-test
result. A selected Fung-wong case illustrates actual geographic alignment,
intensity evolution and model-generated pressure contours, including their
remaining errors and coverage limits.

\section{Overview and forecast state}
The defining constraint is a coupled readout: the route and central pressure
must follow the pressure core generated by the model. A learned,
steering-conditioned proposal moves the core's reference frame; a local
pressure association then determines the reported centre. The method is
therefore neither a pressure-only tracker nor a complete numerical atmospheric
solver. Its displayed pressure is a forecast field, not an independently drawn
vortex placed along a predicted route.

At step $k$, the recurrent state is
\[
s_k=(g_k,h^g_k,c_k,h^c_k,a_k,o_k,z_k,m_k,v_k;G,R,I,M).
\]
\begin{tabularx}{\linewidth}{@{}lX@{}}
\toprule
\textbf{State} & \textbf{Meaning}\\
$g,h^g$ & Eight normalized basin fields and basin memory.\\
$c,h^c,a$ & Core pressure, core memory and pressure anomaly relative to the basin.\\
$o,z,m,v$ & Core-grid origin, associated centre, six-hour motion and auxiliary wind.\\
$G,R,I,M$ & Fixed geography, regional coordinates, issue intensity and validity masks.\\
\bottomrule
\end{tabularx}

Basin channels are $[\mathrm{MSLP},Z_{500},u_{850},v_{850},u_{500},v_{500},u_{200},v_{200}]$
in hPa, metres and metres per second. Normalization uses fixed training-only
statistics, $\widetilde x_j=(x_j-\mu_j)/\sigma_j$. Regional coordinates remain
available when native history is missing. Only information available at or
before issue time may enter inference; retrospective archive coverage does
not establish operational availability. Outputs include basin and regional
pressure, core coordinates, centre, central pressure, masks and auxiliary wind;
there are no quadrant wind radii or resolved surface-wind maps.

\section{Neural operators}\label{sec:operators}
The released model has 21,452,595 trainable parameters.
\subsection{Multiresolution evolution networks}
The basin network receives 44 channels: eight fields, 32 memory features and
four static channels. Encoder widths are $72,144,288,432$; residual-block depths
are $2,2,4,4$. A $3\times3$ stem and stride-two convolutions produce four
scales. The decoder uses $1\times1$ projections, bilinear upsampling, additive
skip connections and one residual block at each reconstructed scale.
Output heads emit ten transition channels and 32 recurrent features. Eight
transition channels are field tendencies and two are flow corrections.

Each residual block comprises a depthwise $5\times5$ convolution, eight-group
normalization, $1\times1$ expansion by four, GELU and $1\times1$ contraction.
A learned residual multiplier starts at 0.01. Transition heads start at zero.
The core network uses widths $64,128,256,384$ and the same depths. Its 45 inputs
are core pressure, eight environmental fields, 32 core-memory channels and four
geographic channels. Three outputs represent one anomaly tendency and two
local-flow corrections.

\subsection{Convolutional recurrent memory}
Basin and core memories each have 32 channels. History encoders receive 72
flattened basin channels or nine pressure-history channels, respectively.
Given advected memory $h$ and new evolution features $f$,
\begin{align*}
(r,u)&=\operatorname{sigmoid}(W_g*[h,f]),\\
q&=\tanh(W_q*[r\odot h,f]),\\
h'&=(1-u)\odot h+u\odot q.
\end{align*}
The gate convolution emits 64 channels split into reset and update gates;
the candidate convolution emits 32. Forecast leads share these recurrent
modules rather than using twenty independent predictors.

\subsection{Environmental attention}
A $1\times1$ convolution projects $[g,h^g,G]$ from 44 to 64 channels.
Average pooling at sizes/strides three and five with ceiling mode yields
$9\times11+5\times7=134$ environmental tokens. Two pre-normalization
Transformer layers use width 64, four heads, feed-forward width 128,
ReLU activation and zero dropout. Each of the 825 basin cells supplies a
query projected from its memory to width 64. Four-head cross-attention
retrieves context; a zero-initialized $64\to32$ projection adds it to basin
memory before the transition. No separate positional embedding is added:
geographic coordinates are already among the token inputs.

\subsection{Observation-conditioned initialization}
Write $\sample(F,\xi)$ for bilinear field sampling. Sampling uses FP32 geometry,
aligned corners and border padding for the basin; transported core anomalies
use zero padding. All nine pressure histories are sampled onto the core grid
centred at the issue observation. A detail mask chooses native pressure or
coarse pressure. The latest map initializes $c_0$, while all nine maps initialize
the core memory.

If issue central pressure is valid, the initial core is corrected by
\[
c_0(x,y)\leftarrow c_0(x,y)+
(\widetilde p_{\rm issue}-c_0(0,0))
e^{-(x^2+y^2)/(2\,100^2)}T(x,y),
\]
where $x,y$ are kilometres and
$T=\operatorname{clip}((640-\sqrt{x^2+y^2})/160,0,1)$.
The anomaly is $a_0=c_0-\sample(g_{0,\mathrm{MSLP}},\xi_0)$.
This compact prior is applied only at initialization. Future scalar pressure
is not repeatedly inserted into the field.

\section{One six-hour forecast transition}
Each step advances the basin first, proposes core motion, transports the core
relative to that motion, and reads out position and pressure. All twenty leads
share the same operators. Sampling $\sample(F,\xi)$ is bilinear; coordinates
and units are explicit below.

\subsection{Environmental transport}
Learned softmax weights blend 850-, 500- and 200-hPa winds; their initial values
are $(0.4,0.4,0.2)$. For basin-network output $d$, the corrected flow and next
normalized basin field are
\begin{align}
U_k &= \sum_\ell\alpha_\ell(u_\ell,v_\ell)_k+15\tanh(d_{8:10}),\label{eq:flow}\\
g_{k+1} &= \sample(g_k,D(U_k))+0.2\tanh(d_{0:8}).\label{eq:basin}
\end{align}
$U_k$ is in m\,s$^{-1}$ and $D$ is the backtraced departure grid. Six hours
convert 1 m\,s$^{-1}$ to 21.6 km. Coordinate conversion uses 111.2 km per
latitude degree and $111.2\max(\cos\phi,0.2)$ km per longitude degree.
The attention-conditioned memory follows the same advection and then a gated
update. This transport is not an exactly conservative atmospheric solver.

\subsection{Moving-frame proposal}
A $44\to64\to3$ GELU MLP reads 32 sampled memory channels, eight basin fields,
previous motion divided by 100, and two issue-intensity masks. For output $b$,
\begin{equation}
m_{k+1}=0.7(21.6)U_k(z_k)+0.3m_k+100\tanh(b_{0:2}).
\end{equation}
This km-per-six-hour displacement defines the proposed origin relative to
$z_k$, not the final reported centre. Auxiliary wind becomes
$v_{k+1}=\max(0,v_k+5b_2)$.

\subsection{Core transport in the moving frame}
The core network reads previous core pressure, the old sampled environment,
memory and geography at the proposed origin. Its local velocity is
$U^{\rm local}=\sample(U_k)+5\tanh(d^c_{1:3})$.
Subtracting $m_{k+1}/21.6$ removes bulk frame motion. The relative departure
grid $D_c$ also accounts for the previous centre--origin offset:
\begin{align}
a_{k+1}&=\sample(a_k,D_c)+0.1d^c_0,\\
c_{k+1}&=\sample(g_{k+1,\mathrm{MSLP}},\xi_{k+1})+Ta_{k+1}.
\end{align}
The anomaly tendency $d^c_0$ is unbounded by $\tanh$. Core memory uses the same
relative sampling followed by its gated update.

\subsection{Pressure-associated readout}
Convert core pressure to hPa, $P=\sigma_p c_{k+1}+\mu_p$. For cells no more
than 300 km from the proposed origin, define
\begin{equation}
w_i=\operatorname{softmax}_i\!\left(-P_i/2-r_i^2/(2\,180^2)\right).
\end{equation}
The weighted mean of cell latitude/longitude gives $z_{k+1}$; central pressure
is $\sample(P,z_{k+1})$, not necessarily the grid minimum. Cells outside the
radius are excluded, reducing association with unrelated depressions.

\subsection{Geographic pressure reconstruction}
The issue-anchored regional field is
\begin{equation}
\widehat p_R=\sample(g_{k+1,\mathrm{MSLP}},R)
 +\sample(Ta_{k+1},R;\mathrm{zero\ padding}),
\end{equation}
then de-normalized to hPa. This is the model's basin-plus-core field; future
observations or display-only vortices are never substituted. Coverage masks
must remain visible. Resampling and local centre association mean the route,
central pressure and displayed field minimum need not coincide exactly.

\section{Training, ensembles and reproducibility}
\subsection{Autoregression and learning objectives}
Inference initializes once and repeats the transition twenty times, using only
fixed issue context and its own predicted future state. The implemented
single-step loss is
\begin{align*}
L={}&L_{\rm env}+L_{\rm regional}+0.2L_{\rm route}
    +0.5L_{\rm pressure}+0.05L_{\rm wind}\\
 &+0.25L_{\Delta p}+0.1L_{\Delta z}.
\end{align*}
The final terms require valid preceding-target labels. Environment loss is
cosine-latitude-weighted Smooth L1 in normalized units. Regional loss includes
Smooth L1 and $0.2$ times adjacent-grid gradient errors on each axis. Absolute
regional-field supervision excludes the inner 150 km around the target centre,
because reanalysis can underresolve observed central pressure. This is a
supervision choice, not proof of correct inner-core structure.

Route residuals use a 100-km scale; pressure and wind use 20 hPa and 30 kt.
Pressure-change error uses 10 hPa and displacement-change error uses 100 km.
All objectives use explicit masks. They train field evolution and readout
together, without adding an independent central-pressure output head.
Training-only normalization, storm-level split boundaries and causal input
selection remain essential implementation constraints.

\subsection{Single forecasts and 50-member means}
Evaluation-mode inference is deterministic for fixed inputs and weights.
The documented ensemble perturbs only normalized historical weather: independent
Gaussian fields are spatially smoothed with kernels five (basin) and nine
(regional), centred, unit-scaled per map and multiplied by amplitudes 0.025 and
0.015. Issue centre, motion, intensity, masks and geography remain fixed.
Each member performs a complete recurrent rollout.

With $M=50$, routes and central pressures are averaged separately:
$\overline z=M^{-1}\sum_m z^{(m)}$ and $\overline p=M^{-1}\sum_m p^{(m)}$.
Physical pressure fields are averaged on common geographic grids, not by
averaging unaligned moving-core array indices. In general,
\[
\overline z\ne\arg\min_x\overline P(x),\qquad
\overline p\ne\min_x\overline P(x).
\]
These are perturbed-input realizations of one model, not 50 trained networks or
learned latent samples. Spread is not automatically calibrated uncertainty.
Member counts, perturbation settings and seed policy must accompany the outputs.

\section{Development evaluation}
\label{sec:evaluation}
\subsection{Matched cases, different forecast pipelines}
The completed comparison uses \textbf{1,473 daily issues from 270 storms},
with 20 six-hour leads per issue. Scores average leads within daily issues,
issues within storms, then storms equally. The cohort was frozen before inference.
Trackformer 1.2 averages 50 causal input perturbations; 1.1 uses its causal
route pipeline. Cases and targets match, but inputs differ. This is broader
development evidence, not an untouched test or architecture ablation.

\subsection{Intensity labels and map coverage}
Pressure truth is JMA best track from IBTrACS \texttt{TOKYO\_PRES}, not a JMA
forecast. Native-detail history was unavailable; $0.25^\circ$ output sampling
does not establish native resolution. From +66 h the centre leaves the fixed
regional patch. The video then shows only the saved coarse basin field there,
while the moving-core readout supplies central pressure. No detailed core is
invented beyond coverage.

There is no verified matched 1.1 pressure array for this benchmark. On the
repeatedly inspected TIP ten-start diagnostic, 1.2 pressure MAE is worse
(30.7 versus 20.1 hPa). Those overlapping starts are not independent tests;
route gains do not establish an all-metric improvement.

\subsection{What remains unverified}
The completed cohort includes 40 recent and 230 historical storms (1980--1999),
outside this checkpoint's fitting and validation years but not certified unused
across prior experiments. Complete five-day truth excludes short remaining
lifetimes. Historical hindcasts use a model trained on later years and
retrospective analyses. Generalization still requires an unused whole-storm
holdout, training-only preprocessing and whole-storm uncertainty resampling.

\subsection{Conclusion}
Trackformer 1.2 links recurrent environmental evolution to a translating
pressure anomaly and coupled geographic readout. Its development results
improve aggregate route measures over the archived 1.1 pipeline, but leave
large absolute errors and intensity failures; the older cohort also showed
a short-lead regression. The
released model is a reproducible research artifact, not a substitute for
official warnings.
